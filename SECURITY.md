# Security policy

## Reporting a problem

Please report security problems privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository. Do not open a public issue. You get an answer within a week.

## Supported versions

| Version | Status |
|---|---|
| v0.4.x (in development on `next`) | Will receive security fixes once released |
| v0.2.x | No further releases. Please upgrade to v0.4.0 when it is released |

v0.4 is a rebuild with security foundations designed in from the start (`design/decisions/ADR-0040-security-foundations.md`). Fixes are developed in the open on `next` with neutral regression tests.
