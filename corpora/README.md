# corpora/

Shared test assets that grow over time: nasty ledgers (globs, CRLF, pushtag, plugins, `@@`), payload corpora (markup in payees and metadata, chart formatters, markdown, SQL/BQL escapes, path traversal), old-workspace fixtures, and anonymized real exports.

**Real exports** (bank and broker statements, CAS, `.eml`) enter only after anonymization by script and **the owner's review of the result**. Each such file is listed in `MANIFEST.tsv` with its SHA-256 and the review date; the T0 staged-file guard refuses any export that is not listed with a matching hash (INV-23). Real ledgers never come here: copies of the owner's ledgers live outside the repo and run only in T-local.

**`ledgers/write/`** is the D1 write corpus: hand-written nasty cases kept as exact bytes (`.gitattributes` `-text`), described by `cases.toml` and checked by `scripts/check_write_corpus.py` and `scripts/oracle/tests/test_write_corpus.py` (spec: `design/specs/write-path/write-corpus.md`). **`ledgers/parity/`** is the parity corpus of INV-03 (S0094): hand-written synthetic cases (custom roots, include forms, options, built-in and local plugins, raw plugin mode, documents roots, Fava's additions, encrypted ledgers that must be refused), described by `cases.toml`; Beancount's example ledger and its variants are generated at test time from the pinned Beancount, never committed. Checked by `engine/tests/ledger/test_parity_corpus.py` (the overlay load equal to Beancount's loader; helpers and the feature inventory in `engine/tests/ledger/parity.py`). Third-party example ledgers are not copied here: generate them from a pinned dependency, or bring their licence and notice to the owner first.

**`ledgers/oracle/`** is the oracle harness's ledger set (S0002). **`ledgers/inv21/`** holds the INV-21 goldens: synthetic ledgers with the TransactionIds, content hashes and metadata JSON v0.2.2's code gives them, and the metadata-key inventory (`keys.toml`), checked by `scripts/oracle/tests/test_inv21_goldens.py` (spec: `design/specs/mirror/inv21-goldens.md`).

**`workspaces/legacy/`** holds the old-workspace fixtures (S0095): `v022-fresh/` is a v0.2.2 install's folder and config right after its setup wizard, made by v0.2.2's own seed code (`scripts/oracle/gen_v022_install.py`, never by hand) and kept as exact bytes. Its `data/` folder is stored as `_data/`, because `.gitignore` ignores every folder named `data`; tests copy the fixture to a temp folder and rename it back. Its goldens are `installs` in `ledgers/inv21/goldens.json`. **`workspaces/manifests/`** holds workspace manifests for the manifest tests (S0051).

**`vectors/`** holds the Beancount domain vectors (S0024): hand-written inputs (`cases.toml`) and what Beancount 3.2.0 says about each (`vectors.json`, written by `scripts/oracle/gen_domain_vectors.py`, never by hand), checked by `scripts/oracle/tests/test_domain_vectors.py` (spec: `design/specs/kernel/vectors.md`).
