- **Part A scope** (agent): BL-0184, BL-0077, BL-0078, BL-0185. Part B (BL-0050, BL-0080) starts after part A is reported; BL-0054 is parked on the owner.
- **The new tag rule only refuses more** (agent): the candidates are the old rule's (tracked files under the same folders, with "test" in the path), then a real test is required. `engine/` stays out of the folders: adding it would accept more, a loosening (BL-0252, inbox).
- **The parametrize rule is left out for capability tags** (agent): `check_invariants.switched_off` gained `parametrize=False`; the enforcement-file rule refuses any parametrize whose list is not a literal, which `backend/tests/workspaces/test_manifest.py` (the repository's own tagged test) uses legitimately. The backend's and engine's pytest configuration fail an empty parameter set at collection, and the run-time proof covers enforcement files. Enforcement files keep the strict rule (default `True`).
- **One report format** (agent): every runner writes JUnit XML. pytest's testcases are matched by `classname` (the collected module, then any class), not by the `file` attribute, which names where a test is defined (an inherited test would be credited to its base). `run_meta_tests.py --junit` names each test by the file of the module that collected it and marks skips, expected failures and fixture skips as skipped.
- **The oracle tests run through `run_meta_tests.py`** (agent): it runs exactly the tests `unittest discover -s scripts/oracle/tests` finds (it already checks the set), in parallel; 266 tests, 4.7 s, as under `discover`. `ci.yml` (manual T1) still runs `discover`; T1 does not run the `--ran` proof.
- **Reports in a `mktemp -d` folder** (agent): fresh at every push, so a stale report from an earlier push cannot pass; removed after the last check (the hook shape rules forbid `trap`, so a push the hook aborts leaves one small temporary folder behind).
- **BL-0185: report, not check** (agent): measured on `fb529a9c`, the active terms over the product source and the models hit 28 lines in 245 files, none stale (dated history comments in `protocol.save`, `protocol.recovery`, `ledger.core.journal`, `ledger.core.history`; Copy's current `legacy_locks` field, 10 lines; the schema generators' `python -I -m` commands; the trim's leftover regex).
