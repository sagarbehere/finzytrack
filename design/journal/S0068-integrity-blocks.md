# S0068: integrity blocks, accounting advises (ADR-0067); R4 becomes reconcile-and-show

## Brief
- Goal: implement the owner's redirection of 2026-10-31. **Job 1 (integrity)** keeps blocking with no override: the new text parses into exactly the intended entries (ADR-0008 steps 1, 2, 2b), the fingerprint and concurrency checks (step 4, the re-check of §6.1 step 6), the atomic write with backup, journal and read-back (steps 5, 6), recovery. **Job 2 (accounting)** only advises: the overlay load (ADR-0010) is a preview whose new errors the user may save anyway; no error class is refused. **R4 becomes reconcile-and-show**: after a save it compares Beancount's real load with the save's prediction, and on a difference logs it and gives a short notice; saving always goes on. Everything that served R4's gate goes.
