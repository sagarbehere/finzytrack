## Decisions
- **All four rows were met by behaviour; the slice pins them and closes them** (agent). No product code changed: the gaps were the checks ENGINEERING and ARCHITECTURE promised and nobody built (EP-25's AST test, EP-13's catch-all allowlist and text-match ban), plus two import contracts. No row needed a scope judgement, a write path or the owner.
- **The tests pin rows already met, so they pass on the base** (agent; PROCESS.md §3 step 3's exemption): the four tree checks carry `@regression-guard` in their module docstrings. Each checker carries planted must-not-pass shapes beside the tree check; the two new import contracts' planted cases fail on the base (the contracts do not exist there).
- **The log line on an `INTERNAL` answer stays on the event loop** (agent; a recorded deviation from EP-25's "file reads and writes run in worker threads"): `EventLog` appends one buffered line under its handler's lock to the local log file, never synced, only when a bug reached the edge. Moving it to a thread (a `QueueHandler`) adds a thread and can lose the line of the bug that crashes the process. Reviewed in `test_async_edge.REVIEWED` with this reason.
- **The catch-all places are what the code has, not "exactly three"** (agent): ARCHITECTURE §6.3 said three places; the code has the API edge, the scheduler thread (its loop, a request's step, one effect, a join, the job runner, Try again's reset) and S0041's rule that a log sink or report receiver that raises loses only its line (seven `contextlib.suppress(Exception)` sites and the stderr pump). Each is reasonable and logged where it can be; §6.3 now says so, and the allowlist counts them per function.
- **SQLite's "no such table" is the one text match** (agent): `query._no_such_table` reads SQLite's message because SQLite reports a missing table only as the generic `SQLITE_ERROR`; it fails closed (any other answer refuses the read). Reviewed in `TEXT_MATCH`; EP-13's ban is about our own errors.
- **L1-10's freshness** (agent): the row moved it to BL-0125, which is done (S0087) and applied by the open (S0088); the focus check is BL-0215 (open). A request's runner reads its pinned generation, so the runner itself needs no check. Closed.
- **L11-03 closed before `ConfigStore` exists** (agent; S0039 had said "the row's own test arrives with ConfigStore"): the test refuses any logging configuration outside the log's constructor, `capture_process` and `close`, so whatever settings store comes later cannot reconfigure the logger and must hand the log a callback. That is the row's rule; waiting for the store adds nothing the check does not already hold.
- **`httpx` is not in `http-at-the-edge`** (agent): it is an HTTP client an adapter may use for a provider (prices, the assistant); the rule is about knowing HTTP statuses and server exceptions.
